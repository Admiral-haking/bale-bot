# 🤝 Contributing to Bale Shop Bot | راهنمای مشارکت

## 🇬🇧 English

We love your input! We want to make contributing to this project as easy and transparent as possible.

### Code of Conduct
- Be respectful and inclusive
- Focus on what is best for the community
- Show empathy towards other community members

### Development Process
1. Fork the repo and create your branch from `main`
2. If you've added code that should be tested, add tests
3. Ensure the code syntax is valid (`python -m py_compile your_file.py`)
4. Update the README.md if needed
5. Issue a pull request

### Pull Request Process
1. Update the README.md with details of changes if needed
2. Update the requirements.txt if you add dependencies
3. The PR will be merged after review

### Code Style
- Follow PEP 8 guidelines
- Use Persian comments for Persian-specific logic
- Use English comments for general logic
- Keep functions focused and small

## 🇮🇷 فارسی

از مشارکت شما بسیار استقبال می‌کنیم!

### فرآیند توسعه
1. ریپازیتوری را Fork کنید
2. برنچ خود را از `main` ایجاد کنید
3. کد خود را اضافه کنید
4. از صحت syntax مطمئن شوید
5. Pull Request ایجاد کنید

### نکات کدنویسی
- از PEP 8 پیروی کنید
- برای منطق فارسی از کامنت فارسی استفاده کنید
- توابع را کوچک و متمرکز نگه دارید
